CARA GANTI FOTO
================
Folder ini berisi 12 foto untuk Sub-game 1 (grid 3x4).
Saat ini isinya placeholder bernomor 1.jpg ... 12.jpg.

Cukup TIMPA file 1.jpg sampai 12.jpg dengan foto kamu sendiri
(pakai nama yang sama: 1.jpg, 2.jpg, dst).

Kalau mau pakai .png, ganti juga daftar nama file di:
  config.js  ->  subgame1.photos

Ukuran ideal: persegi (mis. 400x400) biar grid rapi.
